## 0.1.0（2026-10-18）

首个可用版本。分阶段落地（P0 → P5），每段都实测过再往上垒。

### 悬浮球

- 页面内常驻圆角矩形小球（默认 44×44），位置在右下偏上 —— **刻意避开小鲸鱼挂件**
- **可拖动**：按住移动，松手落盘；位移 < 4px 视为点击（拖动不会误触展开）
- **位置与大小可自主调节**：位置靠拖动，大小用面板里的滑块（32–64px）
- 位置、大小、目标会话都存进 `$DSH_HOME/.fish-orb-state.json`，**刷新/重启后不变**
- 禁用插件时 DOM 会被撤掉（关掉开关球就消失）

### 面板

- 点球展开 / 再点收起 / `Esc` 关闭
- 靠右边缘时向左展开，靠左时向右展开，不超出视口
- 输入框：`Enter` 发送，`Shift+Enter` 换行（`isComposing` 期间不误发）

### 派发

- 面板里选**目标会话**（只列工作区里真实存在的会话，并标注「运行中」/「未打开」）
- 发送后通过 `agent.followup()` 把消息**真投递**进目标会话
- 目标会话没打开 / 没选目标会话 → **明确报错**，不静默失败
- 投递走 `createUserMessage()`（动态 import + 等价兜底），不会写出缺 `role` 的坏消息

### 通知

- 面板关着时收到新任务 → 球右上角**未读小红点**
- 打开面板即视为已读（红点消失），任务列表显示 `result` 摘要

### 未做（明确标记）

- ❌ **会话 AI 的真实回答回流** —— 需要读会话消息流，接口不确定、风险高。当前 `result` 只表示"已投递"
- ❌ 跨应用置顶 / 跨应用划词 / 桌面控制（形态限制，见 `docs/DEVELOPMENT.md` 第 24 条）

### 已知限制

- 只有**正在运行**的会话能收到派发（DSH 的会话必须先打开）
- 派发依赖 `agents` 服务；会话列表依赖 `sessionQuery`（缺失时退到 `sessionController` / `agents.list`）
- 只在 **Windows + DSH 0.2.1-rc.2** 上验证过
